# Learning Roadmap | Roadmap Pembelajaran

The sequence below is a suggested path, not a strict deadline. Revisit earlier topics whenever a later lesson requires them.

Urutan berikut merupakan jalur yang disarankan, bukan tenggat yang kaku. Ulangi materi sebelumnya saat materi lanjutan membutuhkannya.

1. **Environment and Python** — Python setup, NumPy, Pandas, visualization.
2. **Mathematical foundations** — linear algebra, statistics, probability, calculus, optimization.
3. **ML foundations** — learning paradigms, workflow, data preparation, feature engineering.
4. **Supervised learning** — regression and classification algorithms.
5. **Unsupervised learning** — clustering, dimensionality reduction, association.
6. **Evaluation** — metrics, validation, leakage, overfitting, tuning.
7. **Neural networks** — perceptrons, training, backpropagation.
8. **Projects** — reproducible end-to-end case studies.

## Definition of done | Kriteria penyelesaian materi

A topic is considered complete when its concept is explained, code runs, experiments are interpreted, limitations are stated, and references are recorded.

Materi dianggap selesai ketika konsep dijelaskan, kode berhasil dijalankan, eksperimen diinterpretasikan, keterbatasan ditulis, dan referensi dicatat.
