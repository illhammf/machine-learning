# Glossary | Glosarium

| Term | English definition | Penjelasan Indonesia |
|---|---|---|
| Dataset | A collection of data used for analysis or modeling. | Kumpulan data untuk analisis atau pemodelan. |
| Feature | An input variable used by a model. | Variabel masukan yang digunakan model. |
| Label / Target | The value a supervised model learns to predict. | Nilai target yang dipelajari untuk diprediksi model supervised. |
| Training | The process of fitting a model to data. | Proses melatih model menggunakan data. |
| Inference | Using a trained model to produce predictions. | Menggunakan model terlatih untuk menghasilkan prediksi. |
| Overfitting | When a model fits training data too closely and generalizes poorly. | Ketika model terlalu menyesuaikan data latih sehingga kurang baik pada data baru. |
| Generalization | A model's ability to perform on unseen data. | Kemampuan model bekerja pada data yang belum pernah dilihat. |
| Hyperparameter | A configuration value set outside the model's learned parameters. | Nilai konfigurasi yang ditentukan di luar parameter hasil pembelajaran model. |
