# Datasets | Dataset

This directory is for dataset documentation and small files that are permitted to be redistributed.

Direktori ini digunakan untuk dokumentasi dataset dan file kecil yang memang boleh didistribusikan ulang.

For each dataset, document:
- Name and source URL
- License and usage conditions
- Features and target (if applicable)
- Number of rows and columns
- Known limitations and potential bias
- Download or preparation instructions

Untuk setiap dataset, dokumentasikan nama dan sumber, lisensi, fitur dan target, ukuran data, keterbatasan, potensi bias, serta instruksi pengunduhan atau persiapan.

Do not commit large datasets or personal/confidential data. Prefer scripts or instructions that let others obtain data from its official source.
Jangan commit dataset berukuran besar atau data pribadi/rahasia. Utamakan skrip atau instruksi untuk memperoleh data dari sumber resminya.
