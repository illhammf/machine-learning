# Contributing | Panduan Kontribusi

Thank you for considering a contribution! / Terima kasih sudah ingin berkontribusi!

## Before contributing | Sebelum berkontribusi

1. Check existing lessons and issues to avoid duplicate work.
2. Keep explanations accurate, clear, and beginner-friendly.
3. Use bilingual documentation (English and Indonesian).
4. Cite books, papers, articles, and dataset sources.
5. Never commit secrets, private data, or datasets you are not allowed to redistribute.

## Suggested workflow | Alur kontribusi

1. Fork the repository.
2. Create a focused branch: `feat/linear-regression` or `docs/numpy-basics`.
3. Make a small, logically grouped change.
4. Run the relevant code and verify that instructions work.
5. Open a Pull Request describing the change, test performed, and references.

## Lesson checklist | Checklist materi

- [ ] Learning objectives / Tujuan pembelajaran
- [ ] Conceptual explanation / Penjelasan konsep
- [ ] Mathematical intuition where relevant / Intuisi matematika bila relevan
- [ ] Reproducible Python code / Kode Python yang dapat dijalankan ulang
- [ ] Experiment and interpretation / Eksperimen dan interpretasi
- [ ] Limitations and common mistakes / Keterbatasan dan kesalahan umum
- [ ] References and data attribution / Referensi dan atribusi data

## Code conventions | Konvensi kode

- Use descriptive English names for variables and functions.
- Follow PEP 8 where practical.
- Add comments for non-obvious steps, not every line.
- Set random seeds in demonstrations when reproducibility matters.
- Prefer relative paths and avoid machine-specific absolute paths.
