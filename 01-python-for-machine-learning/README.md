# Python for Machine Learning | Python untuk Machine Learning

## Goal | Tujuan

Build the Python skills needed to inspect data, transform it, calculate with arrays, and communicate findings through visualizations.

Membangun keterampilan Python untuk memeriksa data, melakukan transformasi, menghitung menggunakan array, dan menyampaikan temuan melalui visualisasi.

## Modules | Materi

| Module | Focus |
|---|---|
| 01. Python Fundamentals | Variables, data types, control flow, functions |
| 02. NumPy | Arrays, vectorization, broadcasting, linear algebra |
| 03. Pandas | Series, DataFrame, cleaning, grouping, joining |
| 04. Matplotlib | Charts, labels, figures, customization |
| 05. Seaborn | Statistical visualization |

Each module will have its own explanation, runnable examples, and exercises.

Setiap modul akan memiliki penjelasan, contoh yang dapat dijalankan, dan latihan.
